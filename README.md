# BiliLocal · B站直播消费数据分析（本机版）

扫码登录 B站，同步你的直播送礼记录，统计消费、盲盒盈亏、合成活动盈亏。
**全部在你自己的电脑上运行**，登录凭证和数据不经过任何第三方服务器。

> **非官方项目**：本工具与哔哩哔哩（B站）官方没有任何关系，也未获得其授权或认可。「哔哩哔哩」「B站」及相关名称、图标归其各自权利人所有。工具调用的是 B站未公开的接口，随时可能失效；请只用于查看你自己账号的数据，使用风险由你自行承担。

## 启动

```bash
./run.sh
```

浏览器会自动打开 `http://127.0.0.1:8765/`，用 B站 App 扫码登录后点「同步数据」。

先想看看效果？用随机假数据试用（不登录、不联网）：

```bash
./run.sh --demo
```

其它参数：`--port 9000` 换端口，`--no-browser` 不自动开浏览器。

## 功能

| 页面 | 内容 |
|---|---|
| 概览 | 电池消费总额（≈ 人民币）、每月消费、每日消费日历、送得最多的主播和礼物、几点最爱送礼、单笔最大的 10 次 |
| 消费明细 | 全部送礼记录，可按礼物 / 主播搜索、只看包裹礼物或已退回，导出 CSV / JSON |
| 盲盒盈亏 | 每种盲盒的开盒数、花费、爆出价值、盈亏、回报率；爆出分布对比官方概率；按月、按直播间统计 |
| 合成活动 | 按「材料礼物 / 成品礼物」名单计算合成活动盈亏，名单可以在页面上自己改 |
| 勋章与钱包 | 电池 / B币余额，粉丝勋章等级、亲密度、点亮状态（只读） |
| 安全与设置 | 本次启动以来发出的每个网络请求、数据目录、手动补充盲盒 ID、退出登录 |

所有统计页面都可以按时间筛选：全部、本月、上月、近 30 天、近 7 天、今年、自定义。

## 安全设计

B站的登录 Cookie（`SESSDATA`、`bili_jct`）相当于账号的完整权限，交给别人的服务器就等于把账号交出去。这个工具：

- **只连 B站官方**：所有请求只发往 `passport.bilibili.com`、`api.bilibili.com`、`api.live.bilibili.com`，白名单写死在 [`bili.py`](src/bili_local_tool/bili.py) 里，别的地址在发出前就会被拒绝。
- **凭证只在本机**：Cookie 存在数据目录的 `session.json`（权限 600，只有当前系统用户能读）。数据目录默认在 `~/Library/Application Support/BiliLocal`，**不在项目里**：项目放在「文稿」「桌面」时，macOS 的 iCloud 同步会把项目里的文件传上 iCloud。
- **只读**：不送礼、不发弹幕、不点赞、不关注、不删勋章、不领或兑换 B币，也没有抽奖、推荐主播之类的功能。
- **本机服务做了防护**：只监听 `127.0.0.1`；校验 Host 头（防 DNS rebinding）；接口要求每次启动随机生成的令牌，其它网站没法偷偷调用；页面有严格的 CSP，没有任何外部脚本。
- **能撤销**：退出登录时会调用 B站官方退出接口，让这份 Cookie 在 B站那边立即失效。可以选择同时删除本地数据。
- **看得见**：「安全与设置」页实时列出发出的每个请求（只记域名和路径）。

## 数据和计算说明

- 金额单位是**电池**，10 电池 = 1 元。
- B站的消费记录接口**只保留最近约一年**。同步是增量的：数据会一直留在本地，所以定期同步就能攒下超过一年的历史。
- 「电池消费」不含包裹礼物（不花电池）和已退回的记录；包裹礼物价值单独统计。
- 盲盒：盈亏 = 爆出礼物价值 − 盲盒单价 × 开盒数。盲盒会从 B站礼物列表和你的消费记录里自动识别；识别不到的，在「安全与设置」里填礼物 ID 后重新同步。
- 合成活动：支出 = 买材料礼物花的电池，收入 = 合成后进背包的成品送出去时的价值。按礼物名称匹配，每期活动的名单不同，需要自己维护（默认带了「玲珑宝斋」）。

数据目录默认是 `~/Library/Application Support/BiliLocal`（Windows 是 `%LOCALAPPDATA%\BiliLocal`，Linux 是 `~/.local/share/bili-local`），页面「安全与设置」里能看到实际路径。可以用环境变量 `BILI_LOCAL_DATA` 改到别处，但别改到会被 iCloud / 网盘同步的文件夹：

```
BiliLocal/
  session.json            登录凭证
  config.json             合成活动名单、手动补充的盲盒 ID
  blind_boxes.json        盲盒单价和奖池缓存
  uid_<你的UID>/
    pay_records.json      消费记录原始数据
    blind_draws.json      开盒记录
    meta.json             上次同步时间
```

## 代码结构

```
src/bili_local_tool/
  bili.py       B站官方接口客户端（域名白名单、请求记录、App 接口签名）
  storage.py    本地 JSON 存储（原子写入、文件权限）
  analysis.py   纯计算：概览、明细、盲盒、合成活动统计
  service.py    登录、后台增量同步、给页面的数据
  server.py     本机网页服务和接口
  demo.py       演示模式的假数据
  static/       页面（原生 JS + 手画 SVG 图表，不依赖任何 CDN）
tests/          单元测试
```

运行测试：

```bash
PYTHONPATH=src uv run python -m unittest discover -s tests
```

> 项目在 iCloud 同步的「文稿」里时，iCloud 可能给 `.venv` 里的 `.pth` 文件打上隐藏标记，Python 3.12 会跳过它，表现为 `No module named 'bili_local_tool'`。`run.sh` 已经用 `PYTHONPATH` 绕开了；更彻底的办法是把项目挪出 iCloud 同步的文件夹。
